Why does Hill Climbing get stuck?

It only accepts lower ground. In a small dip every nearby spot is higher, so it refuses them all. That dip is a local minimum: the lowest point close by, not on the whole map.

What does temperature do?

It sets how willing Annealing is to gamble. It starts hot and cools each step, so the hiker explores first and settles later. The name comes from slowly cooling metal.

Tk = T₀·αk. Guaranteed convergence needs much slower (logarithmic) cooling, so this is a practical heuristic.

Why “hill climbing” if we seek valleys?

The name comes from searching for the highest point. We flipped the picture so lower is better. The idea is identical.

Where is this used?

Delivery routes, timetables, chip layout and factory scheduling: problems with far too many options to check them all.
